# Seed data

Generated/hand-authored NDJSON documents for the Homepage (now a `page`
document, not a singleton) and its supporting content, per
DOC/SANITY_CMS_ARCHITECTURE.md and DOC/DATA_MODEL.md.

**Imported into the real project (`24jblmse`/`production`) as of Phase 3.2** —
see DOC/PROJECT_STATUS.md. Imported via the HTTP Mutate API directly
(`createOrReplace` per document) rather than `sanity dataset import`, since
that CLI command needs an interactive browser login unavailable in a
sandboxed environment. These files remain the source of truth for that
dataset's content — re-run the generator scripts and re-import (commands
below) after editing them, rather than hand-editing content in Studio and
letting it drift from the committed seed.

## Data-quality notes (University.csv)

- **Fees** mixed plain integers, comma-grouped "lakh" strings, one range value, and a trailing `/-`. Normalized into `quickFacts.feeDisplay` (string) + `feeMin`/`feeMax` (numbers) per DOC/DATA_MODEL.md's field notes; the original raw string is preserved verbatim in `csvLegacyFeeRaw`.
- **Duration** and **Eligibility** are uniform placeholder text across all 30 rows (confirmed in DOC/REQUIREMENTS_ANALYSIS.md § 15, MI-2) — copied as-is into `quickFacts.durationDisplay` / `csvLegacyEligibilityRaw`; real per-university content is still needed before public launch.
- **Three IIM rows** (IIM Lucknow, IIM Kashipur, IIM Rohtak) are government-sector institutes, which BR-2 explicitly rules out ("never counsel on ... government-sector distance programmes"). Imported as data (nothing is silently discarded) but flagged `editorialFlag: "government-sector-do-not-publish"` and excluded from `isFeaturedOnHomepage`.
- **Sikkim Manipal University** carries `editorialFlag: "verification-needed"`, matching the existing flag in DOC/DATA_MODEL.md § 4 ("UGC-DEB status historically complicated — do not publish until confirmed").
- **8 universities** are marked `isFeaturedOnHomepage: true`, matching `design/homepage.html`'s Featured Universities grid exactly, in the same order (`featuredOrder` 1-8): NMIMS, Symbiosis, Amity, Manipal Jaipur, Chandigarh University, Jain, LPU, BITS Pilani.

## How to (re-)import

Via the Sanity CLI, if you have an interactive login available:

```bash
npx sanity dataset import apps/web/sanity/seed/universities.ndjson production --replace
npx sanity dataset import apps/web/sanity/seed/programmes.ndjson production --replace
npx sanity dataset import apps/web/sanity/seed/siteSettings.ndjson production --replace
npx sanity dataset import apps/web/sanity/seed/page-home.ndjson production --replace
```

Run from `apps/web/`, against whichever dataset (`development`/`staging`/`production`) you're seeding. `--replace` avoids a conflict with the existing document of the same `_id`.

Without an interactive login (e.g. a CI job or a sandboxed agent), `createOrReplace` mutations via the HTTP Mutate API with a valid `SANITY_API_READ_TOKEN`-equivalent write token work identically and is how this repo's content was actually (re-)imported in Phase 3.2 — see `POST https://<project>.api.sanity.io/v<version>/data/mutate/<dataset>` with `{"mutations":[{"createOrReplace": <doc>}, ...]}`.
